Exemple de codi Python

A continuació tenim un fragment de codi senzill escrit en Python que calcula el factorial d'un número de manera recursiva: 

def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * factorial(n - 1)

print(factorial(5))  # Imprimeix 120
